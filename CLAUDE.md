## Conventions / gotchas visible from the survey

- The instability-diagnosis-before-chunking ordering is a hard constraint
  from the handoff doc — don't skip to chunking/A-B work without checking
  whether it still holds.
- Fixture choice materially changes results (clean fixture showed a false
  clean win that vanished over repeats) — an apparent effect on one fixture
  is not trustworthy without checking the other and checking repeat spread.
- `mfg-overnight/driver.py`'s `REPO` path is hardcoded to
  `C:\tmp\doc-tools-mfg` — if this worktree is ever moved/removed, that
  script breaks silently until run.
- doc-tools-mfg has no `.mcp.json` or `.claude/` directory — no project-level
  MCP servers or permission config to account for.

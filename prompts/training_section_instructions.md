Analyze the following slides from one section of a training course.
For each slide, extract the key technical concepts it teaches and the other names it uses for them.
For each section, summarize what it teaches and state its learning objectives.

COVERAGE: For EACH slide, list every concept it teaches: its main topic AND each supporting concept it names or explains (each item of a list of types, components, steps or hazards is its own concept). Usually 3 to 6 per slide. The section notes never replace the slide concepts: a concept your summary or objectives mention must also appear on the slide that teaches it.

IMPORTANT: For each concept, assign a "salience" score (0.0 to 1.0) indicating how central it is to its slide:
- 1.0 = The primary topic or main concept being taught
- 0.7 = Important supporting concept, explained in detail
- 0.5 = Related concept mentioned substantively
- 0.3 = Briefly mentioned or referenced
- 0.1 = Appears in footer, header, sidebar, or not directly relevant to the content

Focus on the actual slide content, not headers/footers. Generic terms like "Safety" in a footer should get low salience.
Related terms are only other names for the SAME concept (an abbreviation and its expansion, a synonym the slide uses). A broader topic, a narrower topic or a related idea is not a related term.
Also extract any explicit figure, diagram, or graphic references (e.g., 'Figure 4', 'Diagram 2A'). Only extract resolvable identifiers, never vague references.

DATA HANDLING INSTRUCTIONS:
- Hybrid Tables: Tables are provided in two parts:
    1. ### TABLE STRUCTURE (SPATIAL) ###: A Markdown grid showing column/row alignment. This grid may be sparse due to OCR errors.
    2. ### TABLE CONTENT (SUPPLEMENTAL RAW TEXT) ###: A stream of raw text containing all values from the table. Use this to find missing labels or values absent from the spatial grid.
- Cross-Referencing: If a cell in the spatial grid is empty, check the Supplemental Raw Text to see if the value exists there before assuming it is missing.
